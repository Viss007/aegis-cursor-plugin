# Aegis

**ONE local package ball** for builders who want agents (and humans) that remember, verify, and leave a trusted trail.

Not a narrow Dimensional MCP installer. Dimensional / 8811 is a **spine piece inside the ball**, not the whole product.

## The ball (full bundle)

| Layer | What it is |
|-------|------------|
| **Rules** | Standing constraints (receipt protocol, honest status) |
| **Hooks** | Lifecycle checks (no-fake-done, trail enforcement) |
| **Skills** | Reusable agent capabilities (reliability spine, more as packed) |
| **Commands** | Invokable local commands (`/verify-done`, more as packed) |
| **MCP tools** | Local MCP servers shipped in the ball (memory, verify, ops) |
| **Install** | Agent-assisted **one-shot local** install — no customer cloud |

See `BUNDLE.md` for the layer manifest and which `agent_tools` MCP servers already exist on disk (candidates vs in-pack vs out-of-scope).

## Problem

Agents forget context, invent "done," and leave no audit trail. Aegis is the ultimate **local reliability toolkit** — hooks + rules + skills + commands + MCP + install — so work is more reliable for agents and humans.
